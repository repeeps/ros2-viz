# ROS2, 눈으로 보기

**작은 프로그램(노드) 여러 개가 메시지를 주고받으며 협력한다. 누가 보내고(토픽) · 어떻게 받고(QoS) · 언제 돌고(executor) · 어느 좌표에서(tf) · 어떻게 만나는지(디스커버리) — 그 합주의 악보를 읽는 눈을 기른다.**

ROS2의 **멘탈 모델**을 **수식·코드 없이**, 노드가 켜지고 메시지 패킷이 화살표를 타고 흐르고 큐가 넘쳐 메시지가 버려지고 콜백이 한 줄로 줄 서는 걸 직접 보며 익히는 인터랙티브 학습 자료입니다. 모든 그래프·타이밍·QoS 호환 판정은 **브라우저에서 실시간**으로 계산돼요. 코딩 강좌가 아니라 "**왜 이렇게 도는가**"를 보는 눈을 기르는 게 목표예요.

## 시작하기

`index.html`을 브라우저에서 열면 끝이에요. 빌드도, 설치도 없어요. 처음이라면 **0번 입문**(마스터 없는 노드들의 합주)부터 순서대로.

```
open index.html
```

## 구성 — 0번 입문 + 16챕터 (연결 → 고르기 → 타이밍 → 공간 → 실전)

**0번 · ROS2가 푸는 문제** — 하나의 거대한 프로그램이 아니라, 작은 노드들이 메시지로 협력하는 "마스터 없는 합주". 다섯 질문(누가 받나 / 즉답 / 오래 걸려 / 어떻게 받나 / 언제 도나)으로 시스템을 읽는 법.

- **PART A · 연결** — 01 노드(일하는 작은 단위) · 02 토픽과 발행·구독
- **PART B · 통신 방식** — 03 서비스(요청·응답·데드락) · 04 액션(목표·피드백·취소) · 05 무엇을 쓸까(결정 가이드)
- **PART C · QoS (하이라이트)** — 06 신뢰성(Reliable vs Best Effort) · 07 QoS 불일치(조용한 실패·호환 규칙) · 08 큐와 드롭(depth·KeepLast)
- **PART D · Executor (하이라이트)** — 09 콜백과 spin · 10 단일 스레드(직렬·블로킹·데드락) · 11 멀티 스레드와 콜백 그룹(MutEx/Reentrant·경쟁 상태)
- **PART E · 공간·시스템** — 12 tf2(좌표 트리·시간 보간·timestamp) · 13 디스커버리(DDS·도메인 ID·마스터리스) · 14 시스템 구성(launch·네임스페이스·리매핑·파라미터)
- **PART F · 실전** — 15 빈피킹 캡스톤(노드로 엮기) · 16 너머(다음 발걸음)

각 챕터는 **직관 → 인터랙션 → 결론**의 4스텝으로, 슬라이더·버튼으로 직접 만지며 익혀요.

## 특징

- **수식·코드 없는 직관 입문** — 메시지 패킷이 토픽을 타고 팬아웃하고, QoS가 안 맞아 연결이 조용히 끊기고, 큐가 꽉 차 오래된 메시지가 버려지고, 긴 콜백 하나가 타이머를 놓치게 만드는 걸 눈으로 봐요.
- **모든 판정·시뮬은 실시간 계산** — QoS 호환("요구 ≤ 제공"), 큐 채움/드롭 시뮬, executor 간트 스케줄, tf 시간 보간/외삽, 디스커버리 P2P 연결, 도메인 격리까지 전부 브라우저에서.
- **두 하이라이트** — 입문서가 잘 안 짚는 **QoS(C)**와 **Executor(D)**에 가장 큰 비중. "데이터가 왜 안 들어오지?", "왜 콜백이 가끔 안 돌지?", "왜 멈췄지(데드락)?"의 답을 끝까지.
- **자매 트랙** — "그래스핑·빈피킹, 눈으로 보기"가 *잡는 기하·품질의 원리*라면, 이 트랙은 *노드를 어떻게 연결하나*예요. ROS2(연결) + 그래스핑(잡기) = 빈피킹 한 바퀴. 캡스톤(15)이 둘을 잇습니다.
- **의존성 0** — 순수 HTML+JS. 공통 엔진은 `shared/lib.js`(`VZ.AL` 스텝 플레이어/간트 + `VZ.R3` 3D), ROS2 도메인 렌더러는 `shared/lib-ros.js`(`VZ.ROS` 노드그래프·패킷·시퀀스·간트·큐·QoS 판정·디스커버리), 테마는 `shared/theme.css`.

## 구조

```
index.html              허브
00-intro.html           입문 (마스터 없는 노드들의 합주)
01..16-*.html           16챕터
shared/lib.js           VZ.AL(스텝플레이어·간트) + VZ.R3(3D) + 공통 유틸
shared/lib-ros.js       VZ.ROS — ROS2 도메인 렌더러·QoS 호환 로직
shared/theme.css        다크 테마
shared/favicon.svg
```
